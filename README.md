# РайдерМейкер

Стейдж-плот и input-лист для концертной площадки: расставляете элементы на плане сцены — приложение само собирает список каналов, мониторные миксы и сверку с парком оборудования.

## Возможности

- **Стейдж-плот**: drag-and-drop элементов на план сцены (размер задаётся в метрах), сетка 0,5 м, подписи, зрительный зал.
- **Каталог**: барабаны, бэклайн, микрофоны, оркестр (скрипки, виолончели, контрабас, духовые, медь, литавры, перкуссия, арфа), мониторы, DJ, сценическая мебель.
- **Поворот элементов**: кнопка +45°, клавиша R и свободный угол 0–359° (слайдер / ввод числа).
- **Input-лист**: автоматически собирается из элементов; микрофон, стойка, фантом и примечание редактируются прямо в таблице.
- **Импорт райдера группы**: вставьте текст input-листа — распознаются номера каналов (сохраняются исходные), микрофоны, стойки, фантом; строки миксов (`Mix 1 | Вокал`) попадают в мониторные миксы.
- **Шаблоны составов**: рок-квартет, акустическое трио, кавер-бэнд, DJ-сет.
- **Мониторные миксы**: автоматически из точечных мониторов/сайдфиллов на сцене + импортированные из текста.
- **Сверка с площадкой**: потребность против парка (количество редактируется), подсветка дефицита.
- **Публичная ссылка**: весь райдер упаковывается в URL — можно отправить артисту.
- **Экспорт**: PDF (печать A4), PNG стейдж-плота, XLSX (input-лист / миксы / сверка) для отчётности.
- **PWA**: работает офлайн, ставится на телефон; RU/EN интерфейс.

## Разработка

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # dist/
```

Стек: React 18, TypeScript, Vite, Tailwind CSS, vite-plugin-pwa, lz-string, SheetJS (xlsx).

Иконки PWA (`public/icon-*.png`) — бинарные файлы, в репозитории не хранятся; пересоздаются скриптом:

```bash
pip install pillow
python3 scripts/generate-icons.py
```
